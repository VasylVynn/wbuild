# Ідея №2: платний тест офера «Твій сайт за 999 грн»

> **Дата:** 2026-08-04. **Статус:** ідея, НЕ в роботі. **Походження:** нотатки власника.
> Розвиток гейту R7 (`competitor-roxybo-analysis.md` §9): замість кліків по банеру —
> валідація через **реальні оплати**. Перетинається з погодженими параметрами тесту в
> `partner-discussion-2026-07-29.md` §4 — розбіжності нижче (§3).

---

## 1. Суть (нотатки власника, упорядковано)

- Не викидати вже зроблений продукт — перевірити реальний попит на нього.
- Запустити існуючий генератор, офер: **«Твій сайт за 999 грн»**.
  - Не обіцяти «назавжди».
  - Домен НЕ купувати до оплати.
- Після оплати: користувач перевіряє вільні домени → вибирає → реєструємо
  (вручну або автоматично).
- Рекламний тест **~$200 разом**: ~$20/день, 5–10 днів.
- Мета — **валідація попиту, не масштабування**.
- Критерій успіху: **~5–10+ реальних оплат**.
- Офер перевіряє не тільки раціональну користь, а й **емоційний / імпульсний попит**
  через дешевий і простий офер. *(фрагмент нотаток був обірваний — сенс відновлено,
  підтвердити у власника)*
- Ретаргетинг на тих, хто клікнув / зареєструвався / кинув кошик.

## 2. Чому це сильніше за банерний тест

Клік по банеру — цікавість. Оплата — попит. Гроші на столі = найсильніший сигнал
валідації, який існує. 5–10 оплат за $200 (CAC $20–40 при чеку ~$24) — юніт-економіка
збиткова, і це НОРМАЛЬНО: мета — сигнал, не прибуток.

## 3. Конфлікти з уже погодженим (§4 від 2026-07-29) — вирішити ДО запуску

| Параметр | Погоджено 07-29 | Ця ідея | Статус |
|---|---|---|---|
| Ціна | **₴499** | **₴999** | ❗ конфлікт — узгодити з партнером |
| Бюджет | ~$200/**тиждень** | $200 **разом**, $20/день × 5–10 дн | ❗ конфлікт |
| Домен після оплати | ✅ так | ✅ так | збіг |
| Оплата | WayForPay автоматично (реквізити руками = вбивця конверсії) | не деталізовано | брати WayForPay |
| ₴X — разово чи підписка? | відкрите питання ще з 07-09 | «не обіцяти назавжди» — натяк, але не відповідь | ❗ досі відкрито: що саме купує ₴999? Рік? Далі скільки? |

Позиціонування: flywheel §4.3 казав «машина клієнтів, не сайт за 3 хвилини», а цей
офер — чистий «дешевий сайт». Не суперечність, а вибір: тест валідує САМЕ дешевий
імпульсний офер. Меседжі-кандидати з flywheel §4.1 можна ганяти як A/B в цих же $200.

## 4. Що треба збудувати до тесту (мінімум)

1. **WayForPay** — мінімальна інтеграція (єдиний реально відсутній шматок; RoxyBo
   користується ним же).
2. **Точка пейволу у воронці.** Пропозиція: реклама → лендінг (чат одразу на першому
   екрані, §5 від 07-29) → онбординг-чат → **прев'ю згенерованого сайту безкоштовно**
   → оплата ₴999 → вибір домену. Прев'ю до оплати = і «кинутий кошик» для
   ретаргетингу, і вау-момент для конверсії.
3. **Домен-флоу:** перевірка вільності (API реєстратора або руками) → вибір →
   обіцянка «сайт на домені протягом ~4 годин» (§4 від 07-29). При 5–10 оплатах
   реєстрація руками — норм, автоматизація не потрібна.
4. **Meta Pixel + події** (ViewContent / InitiateCheckout / Purchase) — без цього
   ретаргетинг і оптимізація кампанії неможливі. Наш `/api/events` — внутрішня
   аналітика, піксель це окреме.

## 5. Адверсарні знахідки

- **Ретаргетинг за 5–10 днів на $200 майже не встигне спрацювати:** кастом-аудиторії
  Meta потребують мінімального розміру, а вікно тесту коротке. Тримати як
  «якщо кліків вистачить», не як опору плану. Дешевша альтернатива тим же сигналом —
  ручний фоллоу-ап тим, хто лишив контакт і не оплатив.
- **$20/день × 5–7 днів на 3–4 креативи** — на межі статистичної значущості для A/B.
  Або менше креативів, або довший тест.
- **Оплата ДО прев'ю чи ПІСЛЯ?** Після прев'ю конверсія вища і сигнал чесніший
  (людина платить за конкретний сайт, не за обіцянку), але генерація безкоштовних
  прев'ю коштує токенів + rate-limit захист від зловживань уже є (`lib/rate-limit`).
- **Домен з'їдає маржу:** .com.ua / .ua ~₴200–600/рік з чека ₴999. Для валідації
  байдуже, для прайсингу далі — ні.
- **«Не обіцяти назавжди» без відповіді «а що тоді?»** — юрист-питання лендінгу:
  оферта мусить сказати, що входить (рік хостингу? домен на рік?). Інакше або брехня,
  або відтік на етапі оплати.
- Продажі йдуть на **wizz-app.net** (міграція на 3minsite.com не завершена) — бренд у
  рекламі й на лендінгу мусить збігатися з доменом, інакше довіра падає.

## 6. Гейт і порядок

1. Узгодити з партнером: ціна (₴499 vs ₴999), бюджет ($200 разом vs /тиждень),
   що входить у чек (разово-рік?).
2. Збудувати мінімум з §4 (WayForPay + пейвол + піксель; домени руками).
3. Запустити тест → рахувати ОПЛАТИ, не кліки.
4. 5–10+ оплат → попит є → повертатись до flywheel-послідовності
   (`idea-client-flywheel.md` §4) уже з живими клієнтами.
